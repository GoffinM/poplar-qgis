- les paramètres utilisés : densités max, taille de maille, taux de croissance, année de chaque horizon ;
- une description des étapes manuelles entre le modèle et le script (ajout de l'identifiant, calcul des colonnes `P<année>value`) ;
- la version de QGIS utilisée.
